First-Order ODEs: Separable Equations

Existence & Uniqueness · Separable Method · Initial Value Problems

1.1 What are ODEs?
Definition — First-Order ODE (Standard Form)

An equality of the form

dy/dx = f(x, y)

where f(x,y) is given and y(x) is to be found. Here x is the independent variable, y is the dependent variable.

Definition — Solution of an ODE

A function y = φ(x) is a solution of an ODE on an interval I = {x : a < x < b} if substituting it into the ODE produces an identity for all x ∈ I.

We always seek the maximal continuous interval on which a solution holds.
Definition — Initial Value Problem (IVP)

An ODE together with an initial condition (IC):

$$\frac{dy}{dx} = f(x,\,y), \qquad y(x_0) = y_0$$

Also called a Cauchy problem or one-point boundary value problem.

Types of solutions:

  • Solution in quadratures — a solution expressed as unevaluated integrals.
  • Implicit solution — a solution expressed as an equation relating x and y without isolating y.
  • Explicit solution — y written directly as a function of x.
1.2 Separable Equations
Definition — Separable ODE

An ODE is separable if its right-hand side factors as

$$f(x, y) = F(x)\cdot G(y)$$

i.e., the functions of x and y can be completely separated.

Method — Solving a Separable ODE
  1. Identify special solutions where G(y) = 0 (these give constant solutions).
  2. Separate variables for typical solutions: rewrite as dy / G(y) = F(x) dx.
  3. Integrate both sides: ∫ dy/G(y) = ∫ F(x) dx — this gives the implicit solution.
  4. Solve for y explicitly if possible.
  5. Apply the IC to determine the constant of integration.
  6. State the domain — find the maximal interval containing x₀.
Example — Parachutist (separable IVP)

ODE: dv/dt = 10 − 2v,   v(0) = 0

Special solution: v = 5 m/s.

Separate:

$$\frac{dv}{v-5} = -2\,dt$$

Integrate: ln|v − 5| = C₁ − 2t, so v = 5 + Ce^{−2t}.

Apply IC: v(0) = 5 + C = 0 ⟹ C = −5.

$$v(t) = 5\!\left(1 - e^{-2t}\right)$$

Values: v(1) ≈ 4.32 m/s,   v(2) ≈ 4.91 m/s.

Example — Bolide (domain care required)

ODE: dv/dt = −Dv²,   v(0) = 10 km/s,   D = 0.1

Solution:

$$v(t) = \frac{10}{1+t}, \quad t > -1$$

v(2) ≈ 3.33 km/s. The solution is undefined for t ≤ −1 — never blindly substitute into the formula outside its domain.

1.3 Existence & Uniqueness
Theorem 1.3.1 — Peano's Existence Theorem

For the IVP dy/dx = f(x,y), y(x₀) = y₀, suppose there exists a rectangle R = (α,β) × (γ,δ) with (x₀, y₀) ∈ R such that:

1.f(x,y) is continuous on R.

Then there exists an interval I ∋ x₀ on which the IVP has at least one solution.

Theorem 1.3.2 — Picard's Existence & Uniqueness Theorem

Same setup as Peano, with two conditions on R:

1.f(x,y) is continuous on R. 2.The partial derivative f_y = ∂f/∂y is continuous on R.

Then there exists an interval I ∋ x₀ on which the IVP has a unique solution.

Key observations: No differentiability in x is needed (i.e., f_x need not exist). The interval of uniqueness I may be strictly smaller than the rectangle R. If f_y fails at y = y₀, Picard does not apply and uniqueness may fail.
⚠ Pitfall — Non-Unique Solutions

The ODE dy/dx = 3y^{2/3} has f_y = 2y^{−1/3}, which fails at y = 0. The IC y(x₀) = 0 gives infinitely many solutions — segments of (x−A)³ patched with the zero solution. Always check Picard's conditions before assuming uniqueness.

Example — Applying the Theorems

For dv/dt = −Dv²: we have f = −Dv² continuous everywhere, and f_v = −2Dv also continuous everywhere. Both theorems apply on R = ℝ², so for any IC a unique solution exists. With v(0) = 10, the maximal interval is I = (−1, ∞).

First-Order ODEs: Homogeneous, Linear & Exact

Substitution Methods · Integrating Factor · Potential Functions

2.1 Homogeneous Equations
Definition — Homogeneous Function

A function f(x,y) is homogeneous of degree n if for all t ≠ 0:

$$f(tx, ty) = t^n f(x, y)$$
Definition — Homogeneous ODE

A first-order ODE dy/dx = f(x,y) is homogeneous if f is homogeneous of degree 0, i.e.:

$$f(x, y) = g\!\left(\tfrac{y}{x}\right)$$

Setting t = 1/x in the degree-0 condition gives f(x,y) = f(1, y/x) = g(y/x).

Method — Solving a Homogeneous ODE
  1. Substitute y = xv, so dy/dx = v + x dv/dx (product rule).
  2. The ODE becomes v + x dv/dx = g(v), which rearranges to:
$$\frac{dv}{dx} = \frac{1}{x}[g(v) - v], \quad x \neq 0$$
  1. This is now separable in v and x — solve by the separable method.
  2. Substitute back v = y/x to recover y(x).
  3. State the domain (choice of interval depends on the IC).
Example — x dy/dx = x + y

Rewrite: dy/dx = 1 + y/x = g(y/x) — this is homogeneous.

Let y = xv. Then dv/dx = 1/x, which is separable. Integrating:

$$v = \ln|x| + C$$

Substituting back v = y/x:

$$y(x) = x(\ln|x| + C), \quad x \in (-\infty, 0)\cup(0, \infty)$$
2.2 Linear Equations & the Integrating Factor
Definition — First-Order Linear ODE (Standard Form)

An ODE that is linear in the unknown y:

$$\frac{dy}{dx} + P(x)y = Q(x)$$

Equivalently dy/dx = a(x)y + b(x) with P = −a, Q = b. Coefficients P, Q may be nonlinear functions of x.

Definition — Integrating Factor

The function

$$I(x) = \exp\!\left(\int P(x)\,dx\right)$$

chosen so that multiplying the ODE by I(x) makes the left-hand side a perfect derivative: d/dx[I(x)y]. No arbitrary constant is needed when computing I(x).

Method — Solving a Linear ODE (Integrating Factor Algorithm)
  1. Write in standard form: dy/dx + P(x)y = Q(x).
  2. Compute R(x) = ∫P(x) dx (ignore the arbitrary constant).
  3. Form the integrating factor: I(x) = e^{R(x)}.
  4. Multiply through by I(x); the left-hand side becomes d/dx[I(x)y].
  5. Integrate both sides: I(x)y = ∫I(x)Q(x) dx + C.
  6. Solve for y to get the explicit solution.
$$y = \frac{1}{I(x)}\int I(x)\,Q(x)\,dx + \frac{C}{I(x)}$$
Example 1 — dy/dx + 2xy = 2x

P(x) = 2x, so R(x) = x² and I(x) = e^{x²}.

$$\frac{d}{dx}\!\left[e^{x^2}y\right] = 2x e^{x^2} \implies e^{x^2}y = e^{x^2} + C$$
$$y(x) = 1 + Ce^{-x^2}, \quad x \in \mathbb{R}$$
Example 2 — dy/dx + (3/x)y = 7x³

P = 3/x, so R = 3 ln x and I(x) = x³.

$$x^3 y = 7\int x^6\,dx = x^7 + C \implies y(x) = x^4 + \frac{C}{x^3}$$

Valid on x ∈ (−∞,0) ∪ (0,∞) since P(x) is undefined at x = 0.

Example 3 — dy/dx + 3x²y = 7 (solution in quadratures)

P = 3x², so I(x) = e^{x³}. This gives:

$$e^{x^3} y = 7\int e^{x^3}\,dx + C$$

The integral ∫e^{x³}dx has no closed form in elementary functions — this is a solution in quadratures. It can be evaluated numerically or expressed via special functions.

2.3 Exact Equations
Definition — ODE in Differential Form

A first-order ODE written as:

$$M(x, y)\,dx + N(x, y)\,dy = 0$$

Any ODE dy/dx = f(x,y) can be rewritten in this form in infinitely many ways.

Definition — Exact ODE

The ODE M dx + N dy = 0 is exact in a rectangle R if:

$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \quad\text{for all }(x,y)\in R$$

This is the Schwarz integrability condition.

Theorem 2.3.1 — Existence of Potential Function (Schwarz)

If ∂M/∂y = ∂N/∂x and M, N, M_y, N_x are all continuous on R, then there exists a potential function W(x,y) such that:

$$\frac{\partial W}{\partial x} = M \quad\text{and}\quad \frac{\partial W}{\partial y} = N$$
Theorem 2.3.2 — Solution via Potential Function

If W(x,y) is a potential function, then any y(x) implicitly defined by

$$W(x, y) = C$$

is a solution of M dx + N dy = 0.

Proof: by chain rule, dW/dx = W_x + W_y(dy/dx) = M + N(dy/dx) = 0. ∎

Method — Solving an Exact ODE
  1. Check exactness: verify ∂M/∂y = ∂N/∂x.
  2. Integrate M with respect to x: W = ∫M dx + φ(y).
  3. Determine φ(y) using ∂W/∂y = N, i.e. solve dφ/dy = N − ∂/∂y(∫M dx).
  4. Write the implicit solution: W(x,y) = C.
  5. Solve explicitly for y if possible.
Example 1 — (4x³ + 6xy²)dx + (6x²y + 4y³)dy = 0

M_y = 12xy = N_x ✓ — exact.

$$W = \int(4x^3 + 6xy^2)\,dx = x^4 + 3x^2 y^2 + \varphi(y)$$

W_y = 6x²y + φ'(y) = 6x²y + 4y³ ⟹ φ(y) = y⁴

$$x^4 + 3x^2 y^2 + y^4 = C$$

Explicit form: y = ±√(√(C + 5x⁴/4) − 3x²/2)

Example 2 — (y cos x + 2xe^y)dx + (sin x + x²e^y − 1)dy = 0

M_y = cos x + 2xe^y = N_x ✓ — exact.

$$W = \int(y\cos x + 2xe^y)\,dx = y\sin x + x^2 e^y + \varphi(y)$$

W_y = sin x + x²e^y + φ'(y) = sin x + x²e^y − 1 ⟹ φ(y) = −y

$$y\sin x + x^2 e^y - y = C$$

Cannot be solved explicitly for y — the implicit form is the final answer.

Hierarchy of solvable classes: Separable equations are a special case of exact equations (with M_y = N_x = 0). Exact equations are thus the most fundamental class. However, each class arises so frequently in applications that knowing their specific methods is more efficient than always reducing to exact form.

Second-Order Linear ODEs: Homogeneous Equations

Superposition · Wronskian · Abel's Theorem · Characteristic Equation · Reduction of Order

3.1 Second-Order Linear ODEs
Definition — Standard Form (2nd-Order Linear)
$$y'' + P(x)y' + Q(x)y = R(x)$$

A solution y = φ(x) must be defined on a continuous interval I = (a,b), be twice differentiable, and satisfy the equation at every point of I. The general solution depends on two arbitrary constants.

Theorem 3.1.1 — Existence & Uniqueness (General 2nd-Order)

For the IVP y″ = f(x,y,y′), y(x₀)=y₀, y′(x₀)=y₀′, suppose there is a box B ∋ (x₀,y₀,y₀′) in (x,y,p)-space on which f, f_y, and f_p are all continuous. Then a unique solution exists on some interval I ∋ x₀.

Theorem 3.1.2 — Existence & Uniqueness (Linear Case — Stronger)

If P(x), Q(x), R(x) are continuous on I = (a,b), then for any x₀ ∈ I and any y₀, y₀′, the IVP has a unique solution defined on the entire interval I.

For linear equations, uniqueness holds globally on the interval where coefficients are continuous — not just locally. The interval of existence can be determined before finding the solution.
3.2 Linear Homogeneous Equations
Definition — Homogeneous (2nd-Order Linear)

A second-order linear ODE is homogeneous when the free term is zero:

$$y'' + P(x)y' + Q(x)y = 0$$
Theorem 3.2.1 — Superposition Principle

If y₁(x) and y₂(x) are solutions of the homogeneous equation, then so is any linear combination:

$$y(x) = A\,y_1(x) + B\,y_2(x)$$

Proof: substitute and use linearity of the operator — the two grouped terms each vanish since y₁, y₂ are solutions. ∎

Definition — Linear Independence & the Wronskian

Functions f(x), g(x) are linearly independent (LI) on I if k₁f + k₂g = 0 for all x ∈ I implies k₁ = k₂ = 0; otherwise they are linearly dependent (LD).

The Wronskian of f and g is the determinant:

$$W[f,g](x) = \begin{vmatrix}f & g \\ f' & g'\end{vmatrix} = f g' - f' g$$
Theorem 3.2.2 — LD Functions have Zero Wronskian

If f and g are LD on I, then W[f,g](x) = 0 for all x ∈ I.

Corollary: if W[f,g](x₀) ≠ 0 at any single point, then f and g are LI on any interval containing x₀.

⚠ Caution — Converse is False in General

W = 0 does not imply LD for arbitrary functions. Counterexample: f = x²|x| and g = x³ are LI on ℝ yet W ≡ 0. This failure disappears when the two functions are solutions of a linear ODE (see Abel's theorem below).

Theorem 3.2.3 — Abel's Theorem

If y₁, y₂ are solutions of y″ + P(x)y′ + Q(x)y = 0, then:

$$W[y_1,y_2](x) = C\cdot\exp\!\left(-\int P(x)\,dx\right)$$

where C depends on the choice of y₁, y₂ but not on x.

Corollary: For two solutions of a linear homogeneous ODE, the Wronskian is either identically zero (LD) or nonzero everywhere (LI) — never somewhere zero, somewhere not. So checking W at a single point suffices.

Theorem 3.2.4 — Fundamental System of Solutions

If y₁(x) and y₂(x) are two LI solutions of a second-order linear homogeneous ODE, then every solution can be written as:

$$y(x) = A\,y_1(x) + B\,y_2(x)$$

Such a pair {y₁, y₂} is called a fundamental system of solutions. The constants A and B are uniquely determined by ICs because W[y₁,y₂](x₀) ≠ 0.

3.3 Constant Coefficient Equations
Setup — Characteristic Equation

For the equation with constant coefficients p, q ∈ ℝ:

$$y'' + py' + qy = 0$$

Try y = e^{mx}. Substituting gives e^{mx}(m² + pm + q) = 0, so m satisfies the characteristic (auxiliary) equation:

$$m^2 + pm + q = 0$$
The Three Cases — Roots of the Characteristic Equation

Case 1 — Distinct real roots m₁ ≠ m₂ ∈ ℝ:

$$y = Ae^{m_1 x} + Be^{m_2 x}$$

Case 2 — Repeated real root m₁ = m₂ = m ∈ ℝ:

$$y = (A + Bx)e^{mx}$$

The second LI solution xe^{mx} is derived via reduction of order.

Case 3 — Complex conjugate roots m₁,₂ = α ± iβ:

$$y = e^{\alpha x}[A\cos\beta x + B\sin\beta x]$$

Uses Euler's formula e^{iβx} = cos βx + i sin βx to obtain a real solution.

Example — Pendulum (Physical Context)

A damped pendulum (small angle) satisfies mℓ θ″ = −k θ′ − mg θ. With m=ℓ=1, this gives θ″ + (k/1)θ′ + 9θ = 0.

Overdamped (k=10)

Char. eq: m²+10m+9=0

Roots: m₁=−1, m₂=−9

$$\theta = Ae^{-t} + Be^{-9t}$$

Decays without oscillation

Critically Damped (k=6)

Char. eq: m²+6m+9=0

Double root: m=−3

$$\theta = (A+Bt)e^{-3t}$$

Fastest return, no oscillation

Underdamped (k=2)

Char. eq: m²+2m+9=0

Roots: m = −1 ± 2√2 i

$$\theta = e^{-t}[A\cos(2\sqrt{2}\,t) + B\sin(2\sqrt{2}\,t)]$$

Oscillates with decaying amplitude

Undamped (k=0)

Char. eq: m²+9=0

Roots: m = ±3i

$$\theta = A\cos 3t + B\sin 3t$$

Perpetual oscillation

3.4 Reduction of Order
Problem — Finding a Second Solution Given One

If one solution y₁(x) of y″ + P(x)y′ + Q(x)y = 0 is known, seek y₂ = u(x)·y₁(x) where u(x) is unknown. Since u = 1 is a trivial solution, the equation for u will contain no bare u terms — only u′ and u″. Setting w = u′ reduces it to a first-order equation.

Method — Reduction of Order
  1. Substitute y₂ = u·y₁ into the ODE. Expand and collect terms in u″, u′, u.
  2. The u terms vanish (since y₁ solves the ODE), leaving a first-order equation in w = u′:
$$\frac{dw}{dx} + \!\left(\frac{2y_1'}{y_1} + P(x)\right)\!w = 0$$
  1. Solve this separable/linear equation for w.
  2. Integrate to get u = ∫w dx (discard the arbitrary constant).
  3. Form y₂ = u·y₁.
Alternatively via Abel's theorem: y₂(x) = y₁(x) ∫ W(ξ)/[y₁(ξ)]² dξ where W = exp(−∫P dx).
Example 1 — Repeated root: y″ − 2ay′ + a²y = 0, y₁ = e^{ax}

Let y₂ = ue^{ax}. Substituting and simplifying, the u and u′ terms cancel, leaving:

$$u'' = 0 \implies u = A + Bx$$

So y₂ = (A+Bx)e^{ax} — this is the general solution, from which the second LI basis function is y₂ = xe^{ax}.

Example 2 — (1−x²)y″ − 2xy′ + 2y = 0 on (0,1), given y₁ = x

Let y₂ = ux. Setting w = u′ and separating variables:

$$\int\frac{dw}{w} = -\int\!\left(\frac{2}{x} - \frac{2x}{1-x^2}\right)dx$$

Integrating: w = C/[x²(1−x²)]. Then by partial fractions:

$$u = \int\!\left(\frac{1}{x^2} + \frac{1}{2}\cdot\frac{1}{1-x} + \frac{1}{2}\cdot\frac{1}{1+x}\right)dx = -\frac{1}{x} + \tfrac{1}{2}\ln\!\left|\frac{1+x}{1-x}\right|$$
$$y_2(x) = -1 + \frac{x}{2}\ln\!\left|\frac{1+x}{1-x}\right|$$
Example 3 — x y″ − (x+1)y′ + y = 0, given y₁ = e^x

Let y₂ = ue^x. The u terms cancel. Setting w = u′:

$$x\frac{dw}{dx} + (x-1)w = 0 \implies w = xe^{-x}$$

Integrating by parts: u = ∫xe^{−x}dx = −(x+1)e^{−x}, giving:

$$y_2(x) = -(x+1)$$

Second-Order Linear ODEs: Inhomogeneous Equations

CF + PI · Undetermined Coefficients · Resonance · Variation of Parameters

4.1 General Theory: CF + PI Structure
Theorem 4.1.1 — Difference of Two Particular Solutions

If y₁* and y₂* are both solutions of the inhomogeneous equation, then their difference u = y₂* − y₁* solves the corresponding homogeneous equation.

Proof: subtract the two inhomogeneous equations — the R(x) terms cancel, leaving the homogeneous equation for u. ∎

Structure — General Solution = CF + PI

To solve y″ + P(x)y′ + Q(x)y = R(x):

  1. Find the Complementary Function (CF): the general solution of the homogeneous equation y″ + Py′ + Qy = 0, giving y_h = C₁y₁ + C₂y₂.
  2. Find any one Particular Integral (PI): a single solution y_p of the full inhomogeneous equation.
  3. The General Solution is:
$$y(x) = y_h(x) + y_p(x) = C_1 y_1(x) + C_2 y_2(x) + y_p(x)$$
Theorem 4.1.2 — Superposition for Inhomogeneous Equations

If y_i solves y″ + Py′ + Qy = Rᵢ(x) for i = 1, …, n, then y* = y₁ + ⋯ + yₙ solves:

$$y'' + Py' + Qy = R_1(x) + R_2(x) + \cdots + R_n(x)$$

In practice: split a complicated R(x) into simpler parts, find each PI separately, then add them.

4.2 Method of Undetermined Coefficients (MUC)
Definition — Quasi-Polynomial (QP)

A quasi-polynomial of degree n is a function of the form:

$$f(x) = P_n(x)\,e^{\gamma x}$$

where Pₙ(x) is a polynomial of degree n and γ is a constant. A plain polynomial is a QP with γ = 0. Via Euler's formula, this class also covers trig functions (taking γ = iω).

Theorem 4.2.1 — Non-Resonant Case

For y″ + py′ + qy = Pₙ(x)eᵞˣ, if γ is not a root of the characteristic equation m² + pm + q = 0, then a PI exists of the form:

$$y_p(x) = Q_n(x)\,e^{\gamma x}$$

where Qₙ is a polynomial of degree n with undetermined coefficients to be found by substitution.

Theorem 4.2.2 — Resonant Case (Modification Rule)

If γ is a root of the characteristic equation of multiplicity k (so k = 1 or k = 2), then the PI takes the form:

$$y_p(x) = x^k Q_n(x)\,e^{\gamma x}$$

The factor xᵏ prevents the trial solution from being part of the CF and thus giving a trivial result.

MUC Algorithm
  1. Find the CF by solving the homogeneous equation (characteristic equation, 3 cases from Set 3).
  2. Split R(x) = R₁ + R₂ + ⋯ if needed; handle each part separately (Superposition, Thm 4.1.2).
  3. For each part, identify γ and check whether it equals a root of the characteristic equation (resonance check).
  4. Write the trial solution y_p from the table above. If resonant of multiplicity k, multiply by xᵏ.
  5. Substitute y_p into the ODE and equate coefficients of like terms to get a linear system.
  6. Solve for the undetermined coefficients. Form the general solution: y = y_h + y_p.
Example — y″ − 3y′ − 4y = 3e²ˣ + 5e⁴ˣ + 4x² + 2x − 1

CF: char. eq. m²−3m−4=0, roots m₁=−1, m₂=4. So y_h = C₁e^{−x} + C₂e^{4x}.

R₁ = 3e²ˣ, γ=2

No resonance (2≠−1,4)

Trial: Ae²ˣ

$$A = -\tfrac{1}{2}$$
R₂ = 5e⁴ˣ, γ=4=m₂

Resonance (k=1)

Trial: Bxe⁴ˣ

$$B = 1$$
R₃ = 4x²+2x−1, γ=0

4.4 Variation of Parameters
Motivation — When MUC Cannot Be Used

MUC requires R(x) to be a quasi-polynomial. For arbitrary R(x) (e.g. 1/sin x), we use variation of parameters: replace the constants C₁, C₂ in the CF with unknown functions u₁(x), u₂(x).

Method — Variation of Parameters

Given CF y_h = C₁y₁ + C₂y₂, seek y_p = u₁(x)y₁(x) + u₂(x)y₂(x). The functions u₁′, u₂′ satisfy the system:

$$y_1 u_1' + y_2 u_2' = 0$$
$$y_1' u_1' + y_2' u_2' = R(x)$$

Solving by Cramer's rule and integrating gives the explicit formula:

$$y_p = -y_1(x)\int\frac{y_2(\xi)R(\xi)}{W(\xi)}\,d\xi + y_2(x)\int\frac{y_1(\xi)R(\xi)}{W(\xi)}\,d\xi$$

where W = W[y₁,y₂] is the Wronskian.

Example — y″ + 4y = 1/sin x

CF: y_h = C₁ cos 2x + C₂ sin 2x. MUC fails (not a QP). Let y_p = u₁ cos 2x + u₂ sin 2x.

Solving the system: u₁′ = −cos x, u₂′ = 1/(2 sin x) − sin x. Integrating:

$$u_1 = -\sin x, \quad u_2 = \tfrac{1}{2}\ln\!\left|\frac{1-\cos x}{\sin x}\right| + \cos x$$
$$y = C_1\cos 2x + C_2\sin 2x + \sin x + \tfrac{1}{2}\sin 2x\cdot\ln\!\left|\frac{1-\cos x}{\sin x}\right|$$
MUC vs. Variation of Parameters: MUC (differentiation only) is easier when R(x) is a quasi-polynomial. Variation of parameters (integration required) works for any R(x) but is more involved. When both apply, prefer MUC.

5.1 Boundary-Value Problems: Theory
Definition — Two-Point Boundary-Value Problem (BVP)

A BVP combines a second-order ODE with two boundary conditions (BCs) imposed at two distinct boundary points x₁ ≠ x₂:

$$y'' = f(x, y, y'),\quad g_1\!\left(y(x_1), y'(x_1), y(x_2), y'(x_2)\right) = 0,\quad g_2(\ldots) = 0$$

Separated BCs: each condition involves only one boundary point. Mixed BCs: a condition involves both points (e.g. periodic BCs: y(x₁) = y(x₂), y′(x₁) = y′(x₂)).

Types of Boundary Conditions
1stDirichlet: y(xⱼ) = aⱼ. Prescribes the value. 2ndNeumann: y′(xⱼ) = bⱼ. Prescribes the derivative. 3rdRobin: αⱼy(xⱼ) + βⱼy′(xⱼ) = cⱼ, αⱼ, βⱼ ≠ 0. Mixed value/derivative.

When aⱼ = bⱼ = cⱼ = 0: homogeneous BCs.

Solvability of a Linear BVP

For the linear BVP with general solution y = C₁y₁ + C₂y₂ + y_p, applying Dirichlet BCs reduces solvability to a 2×2 linear system for C₁, C₂. This has a unique solution if and only if:

$$\mathcal{D} = \begin{vmatrix}y_1(x_1) & y_2(x_1)\\y_1(x_2) & y_2(x_2)\end{vmatrix} \neq 0$$
⚠ Key Difference from the Wronskian

Unlike W[y₁,y₂], this determinant 𝒟 can be zero even when y₁ and y₂ are linearly independent. A BVP may have no solution, a unique solution, or infinitely many solutions.

5.2 The Three Possibilities — Worked Examples
y″ + y = 1, y(0) = 0, y(π/2) = 1 → Unique solution

GS: y = A cos x + B sin x + 1. BCs give 1 + A = 0 and 1 + B = 1, so A = −1, B = 0. Here 𝒟 = 1 ≠ 0.

$$y = 1 - \cos x, \quad x \in [0,\tfrac{\pi}{2}]$$
y″ + y = 1, y(0) = 0, y(π) = 1 → No solution

Same GS. BCs give 1 + A = 0 and 1 − A = 1, implying A = −1 and A = 0 — contradiction. Here 𝒟 = 0.

y″ + y = 1, y(0) = 0, y(π) = 2 → Infinitely many solutions

BCs give A = −1, B arbitrary. Here 𝒟 = 0 but the system is consistent.

$$y = 1 - \cos x + B\sin x, \quad x \in [0, \pi],\; B \in \mathbb{R}$$
5.3 Fredholm Alternative & Eigenfunctions
Theorem 5.3.1 — Fredholm Alternative

Let P, Q, R be continuous on [x₁, x₂]. Then exactly one of the following holds:

(i)The inhomogeneous BVP has a unique solution (when 𝒟 ≠ 0). (ii)The corresponding homogeneous BVP has a non-zero solution (eigenfunction, when 𝒟 = 0).

Never both simultaneously. This mirrors the Fredholm alternative for linear algebraic systems.

Definition — Eigenfunction & Eigenvalue

For a BVP depending on a parameter λ:

  • An eigenfunction (EF) is any nonzero solution of the corresponding homogeneous BVP.
  • An eigenvalue is a value of λ for which an eigenfunction exists (i.e. 𝒟(λ) = 0).
  • If φ(x) is an EF, so is Cφ(x) for any C ≠ 0 — eigenfunctions are defined only up to a nonzero scalar.
Method — Finding Eigenvalues & Eigenfunctions
  1. Write the general solution of the ODE in terms of C₁, C₂ (depends on sign of λ — test three cases: λ < 0, λ = 0, λ > 0).
  2. Apply the homogeneous BCs to get a system a₁₁C₁ + a₁₂C₂ = 0, a₂₁C₁ + a₂₂C₂ = 0.
  3. Compute 𝒟(λ). Set 𝒟(λ) = 0 and solve for λ (the eigenvalues).
  4. For each eigenvalue, solve the system for C₁, C₂ (typically one free parameter). Pick a representative (e.g. set free constant = 1) to state each eigenfunction.

6.1 Sturm-Liouville Problems
Definition — Sturm-Liouville (SL) Form

A second-order linear homogeneous ODE in Sturm-Liouville form:

$$-\frac{d}{dx}\!\left[p(x)\frac{dy}{dx}\right] + q(x)y = \lambda r(x)y$$

Equivalently: d/dx[p(x)y′] + [−q(x) + λr(x)]y = 0. The first two derivative terms are combined; the equation depends on the parameter λ in a specific way. Usually p(x) > 0.

Converting Standard Form to SL Form

Given y″ + P(x)y′ + Q(x)y = 0, find p(x) satisfying P(x) = p′(x)/p(x):

$$p(x) = \exp\!\left(\int P(x)\,dx\right)$$

This is exactly the integrating factor from first-order linear ODEs. Multiply through by p(x) to obtain the SL form. Automatically p(x) > 0.

Example: y″ + 8y′ + λy = 0. Here P = 8, so p(x) = e^{8x}. Multiplying gives:

$$-\frac{d}{dx}\!\left[e^{8x}\frac{dy}{dx}\right] = \lambda e^{8x}y$$

with p = e^{8x}, q = 0, r = e^{8x}.

Definition — Sturm-Liouville BVP

A Sturm-Liouville problem (SLP) consists of:

  • The SL ODE: −(p(x)y′)′ + q(x)y = λr(x)y on [x₁, x₂]
  • Separated homogeneous BCs: αⱼy(xⱼ) + βⱼy′(xⱼ) = 0, j = 1, 2
  • Regularity: p, p′, q, r continuous; p(x) > 0 and r(x) > 0 on [x₁, x₂]

Non-trivial solutions are eigenfunctions; values of λ for which they exist are eigenvalues.

Properties of SL eigenvalues & eigenfunctions (stated without proof): all eigenvalues are real and simple (one LI eigenfunction per eigenvalue); all eigenfunctions are real; there are infinitely many eigenvalues, with a minimum but no maximum: λ₁ < λ₂ < λ₃ < ⋯ → ∞.
Inner Products & Orthogonality
Definition — Inner Product in a Functional Space

For functions f(x), g(x) on [x₁, x₂] with weight w(x) > 0:

$$\langle f,\,g\rangle = \int_{x_1}^{x_2} f(x)\,g(x)\,w(x)\,dx$$

The space of functions for which this is defined is denoted L²_w([x₁, x₂]). Functions are treated as vectors; the inner product plays the role of the dot product.

Theorem 6.1.1 — Orthogonality of SL Eigenfunctions

Eigenfunctions φₘ and φₙ of an SLP corresponding to different eigenvalues λₘ ≠ λₙ are orthogonal with weight r(x):

$$\langle\varphi_m,\varphi_n\rangle = \int_{x_1}^{x_2}\varphi_m(x)\,\varphi_n(x)\,r(x)\,dx = 0, \quad \lambda_m\neq\lambda_n$$

Proof sketch: write the SL equations for φₘ and φₙ, multiply cross-wise and subtract, integrate by parts. The boundary terms vanish due to the homogeneous BCs, leaving (λₙ−λₘ)⟨φₙ,φₘ⟩ = 0. ∎

Orthogonality Verified — sin nπx on [0,1]

For y″ + λy = 0, y(0)=y(1)=0: SL form has p=1, q=0, r=1. Eigenfunctions φₙ = sin nπx should be orthogonal with weight 1:

$$\int_0^1 \sin m\pi x\cdot\sin n\pi x\,dx = \tfrac{1}{2}\int_0^1[\cos(m-n)\pi x - \cos(m+n)\pi x]\,dx = 0, \quad m\neq n\;\checkmark$$
6.2 Eigenfunction Expansions & Fourier Series
Theorem 6.2.1 — Eigenfunction Expansion

Let φₙ be orthogonal eigenfunctions of an SLP with weight r(x), and let f and f′ be continuous on [x₁, x₂]. Then:

$$f(x) = \sum_n c_n\,\varphi_n(x), \quad c_n = \frac{\langle\varphi_n,f\rangle}{\langle\varphi_n,\varphi_n\rangle}$$
$$c_n = \frac{\displaystyle\int_{x_1}^{x_2} f(x)\,\varphi_n(x)\,r(x)\,dx}{\displaystyle\int_{x_1}^{x_2} \varphi_n^2(x)\,r(x)\,dx}$$

The series converges to f(x) on the open interval (x₁, x₂). If f also satisfies the BCs of the SLP, it converges at the boundary points too.

Classical Fourier Series (Periodic BCs)

For −y″ = λy with periodic BCs on [0, 2π], we get two LI eigenfunctions per nonzero eigenvalue:

$$\lambda_0 = 0,\;\varphi_0 = 1;\quad \lambda_n = n^2,\;\varphi_n^{(1)} = \cos nx,\;\varphi_n^{(2)} = \sin nx,\quad n\in\mathbb{Z}^+$$

This yields the classical Fourier series:

$$f(x) = a_0 + \sum_{n=1}^\infty (a_n\cos nx + b_n\sin nx)$$
$$a_0 = \frac{1}{2\pi}\int_0^{2\pi}f\,dx, \quad a_n = \frac{1}{\pi}\int_0^{2\pi}f\cos nx\,dx, \quad b_n = \frac{1}{\pi}\int_0^{2\pi}f\sin nx\,dx$$

Note: the constant term may also be written a₀/2, in which case the formula for a₀ uses 1/π.

6.3 Application: Vibrating String (Wave Equation)
Setup — Wave Equation PDE

Motion of a string of length L with tension τ and mass density ρ:

$$\frac{\partial^2 u}{\partial t^2} = a^2\frac{\partial^2 u}{\partial x^2}, \quad a^2 = \frac{\tau}{\rho}, \quad x\in[0,L],\;t\geq 0$$

BCs (fixed ends): u(0,t) = u(L,t) = 0

ICs (initial shape/velocity): u(x,0) = f(x), ∂u/∂t(x,0) = g(x)

Method — Separation of Variables
  1. Assume u(x,t) = X(x)T(t). Substitute into the PDE to separate variables:
$$\frac{X''}{X} = \frac{T''}{a^2 T} = -\lambda \quad\text{(constant, sides depend on different variables)}$$
  1. This gives two ODEs: X″ + λX = 0 with X(0)=X(L)=0 (an SLP), and T″ + λa²T = 0.
  2. The SLP gives eigenvalues λₙ = n²π²/L² and eigenfunctions Xₙ = sin(nπx/L).
  3. For each n, solve T″ + (nπa/L)²T = 0: Tₙ = Aₙ cos(nπat/L) + Bₙ sin(nπat/L).
  4. Superpose: u = Σ uₙ where each uₙ = Tₙ(t)·Xₙ(x) satisfies the BCs.
  5. Apply ICs: expand f(x) and g(x) in eigenfunctions to find Aₙ and Bₙ.
Solution — Vibrating String
$$u(x,t) = \sum_{n=1}^\infty (A_n\cos n\omega t + B_n\sin n\omega t)\sin nkx$$

where ω = πa/L, k = π/L, and:

$$A_n = \frac{2}{L}\int_0^L f(x)\sin\!\left(\frac{n\pi x}{L}\right)dx, \quad B_n = \frac{2}{n\pi a}\int_0^L g(x)\sin\!\left(\frac{n\pi x}{L}\right)dx$$

The solution is periodic in time with period 2π/ω = 2L/a = 2L√(ρ/τ) regardless of initial conditions.

Modes & harmonics: each partial solution uₙ is a harmonic with spatial period 2L/n and temporal period 2π/(nω). All are integer multiples of the fundamental frequency ω. If ρ is not constant, the SL frequencies are not integer multiples — the string no longer produces a clean musical tone. Restricting to even-n modes raises the pitch by one octave (flageolet technique).
6A — Fourier Series: Detailed Theory
Definition — Periodic Function & Fourier Series

A function f(x) is periodic with period T if f(x+T) = f(x) for all x. The Fourier series of a 2π-periodic function is:

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty [a_n\cos nx + b_n\sin nx]$$

Note: the constant term is written as a₀/2 (not a₀) so that the formula for aₙ holds uniformly for n = 0 and n ≥ 1.

Euler-Fourier Formulae — Deriving the Coefficients

Integrating against 1, cos mx, sin mx and using orthogonality ∫_{−π}^{π} cos nx dx = ∫_{−π}^{π} sin nx dx = 0:

$$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\cos nx\,dx, \quad n\in\mathbb{Z}^+\cup\{0\}$$
$$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi}f(x)\sin nx\,dx, \quad n\in\mathbb{Z}^+$$

The term aₙ cos nx + bₙ sin nx is called the n-th harmonic.

Example — f(x) = x on (−π, π)

Since f(x) = x is odd, all cosine coefficients vanish (aₙ = 0). For the sine coefficients:

$$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi}x\sin nx\,dx = \frac{2}{n}(-1)^{n+1}$$
$$x = 2\sum_{n=1}^\infty \frac{(-1)^{n+1}}{n}\sin(nx), \quad x\in(-\pi,\pi)$$

At discontinuities x = ±(2k+1)π, the series converges to 0 (the average of the left and right limits (−π + π)/2 = 0).

Theorem 6A.1.1 — Dirichlet's Convergence Theorem

Let f(x) be bounded, 2π-periodic, with only finitely many maxima, minima, and discontinuities (all simple jumps) on [−π, π). Then the Fourier series converges at every x to:

$$\tfrac{1}{2}[f(x^+) + f(x^-)] = \tfrac{1}{2}\!\left[\lim_{\varepsilon\to 0^+}f(x+\varepsilon) + \lim_{\varepsilon\to 0^+}f(x-\varepsilon)\right]$$

At points of continuity this equals f(x); at jump discontinuities it equals the midpoint of the jump. The conditions are called Dirichlet conditions.

Theorem 6A.2.1 — Even & Odd Functions

If f is even on (−π, π): only cosine terms survive (bₙ = 0):

$$a_n = \frac{2}{\pi}\int_0^\pi f(x)\cos nx\,dx$$

If f is odd on (−π, π): only sine terms survive (aₙ = 0):

$$b_n = \frac{2}{\pi}\int_0^\pi f(x)\sin nx\,dx$$

Even × even = even; odd × even = odd; odd × odd = even. Integral of odd function over symmetric interval is zero.

Example — Square wave: f(x) = −1 on (−π,0), f(x) = 1 on (0,π)

f is odd, so aₙ = 0. Using the odd-function formula:

$$b_n = \frac{2}{\pi}\int_0^\pi\sin nx\,dx = \frac{2}{\pi n}(1-\cos n\pi) = \begin{cases}0 & n\text{ even}\\4/(\pi n) & n\text{ odd}\end{cases}$$
$$f(x) = \frac{4}{\pi}\sum_{m=0}^\infty \frac{\sin(2m+1)x}{2m+1}$$
Extension to Arbitrary Interval (−ℓ, ℓ)

Scale x → ℓz/π (i.e. z = πx/ℓ). The Fourier series on (−ℓ, ℓ) becomes:

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty\!\left[a_n\cos\!\left(\frac{n\pi x}{\ell}\right) + b_n\sin\!\left(\frac{n\pi x}{\ell}\right)\right]$$
$$a_n = \frac{1}{\ell}\int_{-\ell}^{\ell}f(x)\cos\!\left(\frac{n\pi x}{\ell}\right)dx, \quad b_n = \frac{1}{\ell}\int_{-\ell}^{\ell}f(x)\sin\!\left(\frac{n\pi x}{\ell}\right)dx$$

The series has period 2ℓ and represents only periodic functions — it cannot represent an arbitrary function on (−∞, ∞).

Example — f(x) = 0 on (−2,0), f(x) = 1 on (0,2), ℓ = 2

a₀ = 1, aₙ = 0 for n ≥ 1, and bₙ = (1−cos nπ)/(nπ). Therefore:

$$f(x) = \tfrac{1}{2} + \sum_{n=1}^\infty\frac{1-\cos n\pi}{n\pi}\cdot\sin\!\left(\frac{n\pi x}{2}\right)$$

The nonzero bₙ terms occur only for odd n, where 1 − cos nπ = 2.

Series Solution Method

7.1 Power Series Theory
Definition — Power Series & Convergence

A power series at x₀ has the form Σₙ₌₀^∞ aₙ(x−x₀)ⁿ. It always converges at x = x₀; it may converge for all x or only some x. The series converges absolutely at x if Σ|aₙ||x−x₀|ⁿ converges. Absolute convergence implies convergence.

Radius of Convergence — Ratio Test

Apply the ratio test with r = limₙ→∞ |aₙ₊₁/aₙ| · |x−x₀|. If L = limₙ→∞ |aₙ₊₁/aₙ| exists, the radius of convergence is:

$$\rho = \frac{1}{L}\;(L>0);\quad \rho = \infty\;(L=0);\quad \rho = 0\;(L=\infty)$$

The series converges absolutely for |x−x₀| < ρ, diverges for |x−x₀| > ρ. At the boundary |x−x₀| = ρ, convergence must be checked separately.

Taylor Series & Analytic Functions

If Σaₙ(x−x₀)ⁿ converges to f(x) for |x−x₀| < ρ, then aₙ = f⁽ⁿ⁾(x₀)/n! (Taylor series). A function is analytic at x₀ if it has such a Taylor series with ρ > 0.

  • Sums, products of analytic functions are analytic. Quotients f/g are analytic at x₀ provided g(x₀) ≠ 0.
  • Series equality: if Σaₙ(x−x₀)ⁿ = Σbₙ(x−x₀)ⁿ for all x in an interval, then aₙ = bₙ for all n.
7.2 Solving ODEs Using Power Series
Ordinary vs. Singular Points

For a(x)y″ + b(x)y′ + c(x)y = 0 with polynomial coefficients, the point x₀ is an ordinary point if a(x₀) ≠ 0. At an ordinary point, P = b/a and Q = c/a are analytic, and a power series solution exists. Otherwise x₀ is a singular point.

Theorem 7.2.1 — Convergence of Power Series Solutions

Let x₀ be an ordinary point of y″ + P(x)y′ + Q(x)y = 0 where P, Q are analytic. Then the solution

$$y(x) = \sum_{n=0}^\infty a_n(x-x_0)^n = a_0 y_1(x) + a_1 y_2(x)$$

is analytic with radius of convergence ρ ≥ min(ρ_P, ρ_Q). Practical rule: find the nearest singular point x* to x₀; then ρ ≥ |x* − x₀|.

Method — Series Solution at an Ordinary Point
  1. Assume y(x) = Σaₙ(x−x₀)ⁿ. Differentiate term by term: y′ = Σnaₙ(x−x₀)ⁿ⁻¹, y″ = Σn(n−1)aₙ(x−x₀)ⁿ⁻².
  2. Substitute into the ODE. Shift summation indices so all series run over the same power (x−x₀)ⁿ.
  3. Combine into a single series and set the coefficient of each (x−x₀)ⁿ to zero.
  4. This gives a recurrence relation (RR) expressing each aₙ in terms of earlier coefficients.
  5. Solve the RR separately for even and odd indexed coefficients (they depend on a₀ and a₁ respectively). Write as y = a₀y₁ + a₁y₂.
  6. Verify W[y₁,y₂](x₀) ≠ 0 to confirm a fundamental system.
Index shifting rule: to standardise the generic term to xⁿ, substitute m = n + k (or n − k). All occurrences of the index inside the sum shift accordingly; the lower limit shifts in the opposite direction.
7.3 Example — Harmonic Oscillator: y″ + y = 0
Series solution about x = 0 (all points ordinary, ρ = ∞)

Assume y = Σaₙxⁿ. Substituting and shifting the index in y″:

$$\sum_{n=0}^\infty [(n+2)(n+1)a_{n+2} + a_n]\,x^n = 0$$

Recurrence relation:

$$a_{n+2} = \frac{-a_n}{(n+2)(n+1)}, \quad n \geq 0$$

Even coefficients (from a₀): a₂ₖ = (−1)ᵏ a₀ / (2k)!

Odd coefficients (from a₁): a₂ₖ₊₁ = (−1)ᵏ a₁ / (2k+1)!

$$y = a_0\sum_{n=0}^\infty\frac{(-1)^n x^{2n}}{(2n)!} + a_1\sum_{n=0}^\infty\frac{(-1)^n x^{2n+1}}{(2n+1)!}$$

These are exactly y = a₀ cos x + a₁ sin x. The ratio test confirms ρ = ∞ for each series. The Wronskian at x=0 is W = 1 ≠ 0, confirming a fundamental system.

7.4 Example — Airy Equation: y″ − xy = 0
Series solution about x = 0 (all points ordinary, ρ = ∞)

Assume y = Σaₙxⁿ. Substituting and shifting indices:

$$2a_2 + \sum_{n=1}^\infty[(n+2)(n+1)a_{n+2} - a_{n-1}]\,x^n = 0$$

Recurrence relation: a₂ = 0, and

$$a_{n+3} = \frac{a_n}{(n+2)(n+3)}, \quad n \geq 0$$

Since a₂ = 0, the pattern splits into three streams depending on n mod 3:

  • a₂ = a₅ = a₈ = ⋯ = 0
  • Coefficients a₃, a₆, a₉, … depend on a₀
  • Coefficients a₄, a₇, a₁₀, … depend on a₁
$$a_{3k} = \frac{(3k-2)!!!}{(3k)!}\,a_0, \quad a_{3k+1} = \frac{(3k-1)!!!}{(3k+1)!}\,a_1$$

Using the triple factorial notation: (3k)!!! = 3·6⋯(3k), (3k+1)!!! = 1·4⋯(3k+1).

$$y = a_0\!\left[1 + \frac{x^3}{6} + \frac{x^6}{180} + \cdots\right] + a_1\!\left[x + \frac{x^4}{12} + \frac{x^7}{504} + \cdots\right]$$

W[f,g](0) = 1 ≠ 0 — fundamental system confirmed. Ratio test: ρ = ∞ for both series.

The Airy equation cannot be solved by any of the other methods in this module (constant-coefficient methods, MUC, variation of parameters). The power series method is the only systematic approach available here.

8P.2 Eigenvalues, Eigenvectors & Diagonalisation
Definition — Eigenvalue & Eigenvector of a Matrix

For A ∈ ℂ^{N×N}, a scalar λ ∈ ℂ and nonzero vector v ∈ ℂᴺ satisfying

$$A\mathbf{v} = \lambda\mathbf{v}, \quad \mathbf{v}\neq\mathbf{0}$$

are called an eigenvalue and corresponding eigenvector of A. If v is an eigenvector for λ, so is kv for any k ≠ 0.

Finding Eigenvalues — Characteristic Equation

Av = λv has a non-trivial solution v if and only if A − λI is singular:

$$\det(A - \lambda I) = 0$$

This is the characteristic equation of A. For an N×N matrix it is a degree-N polynomial in λ.

  • Algebraic multiplicity mⱼ: the multiplicity of λⱼ as a root of det(A−λI)=0. Sum: Σmⱼ = N.
  • Geometric multiplicity ℓⱼ: number of LI eigenvectors for λⱼ. Always 1 ≤ ℓⱼ ≤ mⱼ.
Theorem 8P.2.1 — Eigenvectors for Distinct Eigenvalues are LI

If λ₁, …, λₙ are distinct eigenvalues with corresponding eigenvectors v¹, …, vⁿ, then v¹, …, vⁿ are linearly independent.

Proof: assume Σαᵢvⁱ = 0; repeatedly premultiply by (A−λᵢI) to isolate each αᵢ = 0 (using λᵢ ≠ λⱼ). ∎

Finding Eigenvectors — Three Methods

Method 1 (always works): Row-reduce (A − λⱼI | 0) to REF; identify free variable and read off eigenvector.

Method 2 (adjugate): Let B = A − λⱼI. Any nonzero column of adj(B) (the transposed cofactor matrix) is an eigenvector, since B·adj(B) = (det B)I = 0.

Method 3 (projection): For distinct eigenvalues, compute vᵏ = ∏ⱼ≠ₖ (A − λⱼI) · u for a generic vector u (e.g. a standard basis vector).

Diagonalisation

If A has N LI eigenvectors v¹,…,vᴺ with eigenvalues λ₁,…,λᴺ, form the modal matrix P = [v¹ | ⋯ | vᴺ] (eigenvectors as columns). Then:

$$AP = P\Lambda \implies P^{-1}AP = \Lambda = \mathrm{diag}(\lambda_1,\ldots,\lambda_N)$$

Λ is the diagonal matrix of eigenvalues in the same order. If A has fewer than N LI eigenvectors, it cannot be diagonalised in this way.

Example — Diagonalise A = [[3,2,2],[1,4,1],[−2,−4,−1]]

Characteristic equation: det(A−λI) = −λ³+6λ²−11λ+6 = −(λ−1)(λ−2)(λ−3) = 0.

Eigenvalues: λ₁=1, λ₂=2, λ₃=3. Row-reducing (A−λⱼI|0) for each:

$$\mathbf{v}^1 = (-1,0,1)^\top, \quad \mathbf{v}^2 = (-2,1,0)^\top, \quad \mathbf{v}^3 = (0,-1,1)^\top$$
$$P = [\mathbf{v}^1|\mathbf{v}^2|\mathbf{v}^3], \quad P^{-1}AP = \mathrm{diag}(1,2,3) = \Lambda$$
8P.4 Systems of First-Order Linear ODEs
Matrix Form — Linear System

A system of n first-order linear ODEs:

$$\dot{\mathbf{x}} = A(t)\mathbf{x}(t) + \mathbf{f}(t)$$

where x(t) = (x₁,…,xₙ)ᵀ, A(t) is the n×n coefficient matrix, f(t) is the forcing vector. Homogeneous when f = 0.

Converting Between Systems and Higher-Order ODEs

Higher-order → system: for y″ = P(t)y′ + Q(t)y + R(t), let x₁ = y, x₂ = y′:

$$\dot{\mathbf{x}} = \begin{pmatrix}0&1\\Q(t)&P(t)\end{pmatrix}\mathbf{x} + \begin{pmatrix}0\\R(t)\end{pmatrix}$$

System → higher-order: eliminate variables by differentiation and substitution. E.g. from ẋ₁ = 3x₁+2x₂, ẋ₂ = 4x₁+5x₂, differentiate the first and substitute the second to get ẍ₁ = 8ẋ₁ − 7x₁.

Theorem 8P.4.1 — Picard's Theorem for Systems

For ẋ = f(t,x) with IC x(t₀) = x⁰, if f and all partial derivatives ∂fⱼ/∂xₖ are continuous in a box B ∋ (t₀, x⁰), then a unique solution exists on some interval I ∋ t₀.

Key Theorems for Linear Systems
1.If aⱼₖ(t) and fⱼ(t) are continuous on I, a unique solution exists on all of I (global, not just local). 2.Superposition: if x⁽¹⁾, x⁽²⁾ solve the homogeneous system, so does c₁x⁽¹⁾ + c₂x⁽²⁾. 3.There exist n LI solutions of the homogeneous system; the general solution is c₁x⁽¹⁾ + ⋯ + cₙx⁽ⁿ⁾. 4.GS = CF + PI: general solution of inhomogeneous system = particular solution + general solution of homogeneous system.
Analogy with 2nd-order ODEs: theorems for linear systems mirror those for linear second-order ODEs exactly — superposition holds, the general homogeneous solution is an n-parameter family, and inhomogeneous solutions have the CF + PI structure. The key new ingredient is matrix diagonalisation as the tool for finding the fundamental solutions.

8.1 Homogeneous Systems
General Solution — Homogeneous Constant-Coefficient System

For ẋ = Ax with A constant, try x(t) = ve^{λt}. Substituting gives λve^{λt} = Ave^{λt}, so Av = λv — an eigenvalue problem.

If A has n LI eigenvectors v¹,…,vⁿ with eigenvalues λ₁,…,λₙ, the general solution is:

$$\mathbf{x}(t) = C_1\mathbf{v}^1 e^{\lambda_1 t} + C_2\mathbf{v}^2 e^{\lambda_2 t} + \cdots + C_n\mathbf{v}^n e^{\lambda_n t} = P\cdot(C_1 e^{\lambda_1 t},\ldots,C_n e^{\lambda_n t})^\top$$

where P = [v¹|⋯|vⁿ]. For an IVP x(0) = x⁰, solve PC = x⁰ for the constants C = (C₁,…,Cₙ)ᵀ.

Example — 3×3 System with Distinct Real Eigenvalues

For the matrix from Set 8P with λ₁=1, λ₂=2, λ₃=3 and eigenvectors v¹=(−1,0,1)ᵀ, v²=(−2,1,0)ᵀ, v³=(0,−1,1)ᵀ:

$$\mathbf{x}(t) = C_1(-1,0,1)^\top e^{t} + C_2(-2,1,0)^\top e^{2t} + C_3(0,-1,1)^\top e^{3t}$$
Complex Eigenvalues — Real Form of Solution

For ẋ = [[0,−ω],[ω,0]]x: characteristic equation λ²+ω²=0, roots λ = ±iω.

The complex solution A(1,−i)ᵀe^{iωt} + B(1,i)ᵀe^{−iωt} is converted to real form using e^{±iωt} = cos ωt ± i sin ωt. Setting C₁ = A+B, C₂ = i(A−B):

$$x(t) = C_1\cos\omega t + C_2\sin\omega t, \quad y(t) = -C_2\cos\omega t + C_1\sin\omega t$$
For complex eigenvalues α ± iβ: the real general solution is built from e^{αt}cos βt and e^{αt}sin βt terms, analogous to the scalar second-order case.
8.2 Inhomogeneous Systems: Method of Undetermined Coefficients
MUC for Systems — Theory

For ẋ = Ax + f(t) with f(t) = Pₘ(t)e^{γt} (vector quasi-polynomial):

  • Non-resonant (det(A−γI) ≠ 0): trial solution x_p = be^{γt}. Substituting gives (A−γI)b = −a, a linear system for the vector b.
  • Resonant (γ is an eigenvalue of multiplicity k): multiply trial by tᵏ.

GS = CF + PI, exactly as for scalar equations.

Example — ẋ = Ax + (7,1,−12)ᵀe^{6t}, γ=6 (non-resonant)

Eigenvalues of A are 1, 2, 3 so γ=6 is not an eigenvalue. Try x_p = be^{6t}:

$$(A-6I)\mathbf{b} = -(7,1,-12)^\top \implies \mathbf{b} = (1,0,-2)^\top$$
$$\mathbf{x} = (1,0,-2)^\top e^{6t} + C_1(-1,0,1)^\top e^{t} + C_2(-2,1,0)^\top e^{2t} + C_3(0,-1,1)^\top e^{3t}$$
8.3 Inhomogeneous Systems: Method of Diagonalisation
Method — Diagonalisation

Works for any f(t) (not restricted to quasi-polynomials), provided A has n LI eigenvectors.

  1. Diagonalise A: find P (eigenvector columns) so that P⁻¹AP = Λ.
  2. Substitute x = Py. Pre-multiply the system by P⁻¹:
$$\dot{\mathbf{y}} = \Lambda\mathbf{y} + \mathbf{g}(t), \quad \mathbf{g}(t) = P^{-1}\mathbf{f}(t)$$
  1. Since Λ is diagonal, this decouples into n independent first-order equations:
$$\dot{y}_j = \lambda_j y_j + g_j(t), \quad j = 1,\ldots,n$$
  1. Solve each equation by the integrating factor method:
$$y_j(t) = e^{\lambda_j t}\!\left[\int e^{-\lambda_j\tau}g_j(\tau)\,d\tau + C_j\right]$$
  1. Recover x = Py.
Example — Double eigenvalue: A has λ₁=λ₂=−3 (mult. 2), λ₃=−6

For A = diag(−4,−4,−4) + [[0,−1,−1],[−1,0,−1],[−1,−1,0]]: characteristic equation −(λ+3)²(λ+6) = 0.

For λ₁,₂ = −3: equation α+β+γ=0 gives two free parameters — geometric multiplicity 2 = algebraic multiplicity 2 — so complete set of eigenvectors exists:

$$\mathbf{v}^1 = (-1,1,0)^\top, \quad \mathbf{v}^2 = (-1,0,1)^\top, \quad \mathbf{v}^3 = (1,1,1)^\top$$

After diagonalisation, the system decouples into three scalar ODEs. When f = (3/(t+1), 0, 0)ᵀ, the integrals involve the Exponential Integral Ei(x) = ∫_{−∞}^x eᵗ/t dt — a solution in special functions, since ∫e^{3t}/(1+t) dt has no elementary form.

Special Function — Exponential Integral Ei(x)
$$\mathrm{Ei}(x) = \int_{-\infty}^x \frac{e^t}{t}\,dt, \quad x\neq 0$$

Key properties: d/dx[Ei(x)] = eˣ/x. Useful identities:

$$\int\frac{e^{kx}}{x}\,dx = \mathrm{Ei}(kx) + C$$
$$\int\frac{e^{kt}}{t+a}\,dt = e^{-ka}\,\mathrm{Ei}(k(t+a)) + C$$
MUC vs. Diagonalisation for systems: MUC is simpler (no matrix inversion) but only applies to quasi-polynomial forcing. Diagonalisation applies to any f(t) but requires solving n integrals which may involve special functions. The two methods give identical results when both apply.

First-Order ODEs
CT1 Separable ODE ▾
1
Identify that the ODE can be written as dy/dx = F(x)·G(y). If not separable, try a different method.
2
Find special solutions: set G(y) = 0 and note any constant solutions. These cannot be recovered from the general solution.
3
Separate variables: rewrite as dy/G(y) = F(x)dx and integrate both sides: ∫dy/G(y) = ∫F(x)dx + C.
4
Solve for y explicitly if possible. Otherwise leave as an implicit solution.
5
Apply IC if given (IVP). State the maximal domain (the interval containing x₀).
Generalised example

dy/dx = (1+y²)sin x, y(0) = 1.

No special solutions (1+y² > 0 always). Separate: dy/(1+y²) = sin x dx. Integrate: arctan y = −cos x + C. IC: arctan 1 = −1 + C ⟹ C = π/4+1. So y = tan(−cos x + π/4 + 1).

⚠ Always check for special solutions before separating. Check whether the IC is also satisfied by a special solution.
CT1 First-Order Linear ODE — Integrating Factor ▾
1
Write in standard form: dy/dx + P(x)y = Q(x). Move all y terms to the left.
2
Compute R(x) = ∫P(x)dx — no arbitrary constant needed here.
3
Form integrating factor: I(x) = e^{R(x)}.
4
Multiply through by I(x). The left side must become d/dx[I(x)y] — verify this.
5
Integrate both sides: I(x)y = ∫I(x)Q(x)dx + C. Include the +C here.
6
Divide by I(x) to get y. Apply any IC to find C.
Generalised example

dy/dx + (2/x)y = x² on x > 0.

P = 2/x, R = 2ln x, I = x². Multiply: d/dx[x²y] = x⁴. Integrate: x²y = x⁵/5 + C. So y = x³/5 + C/x².

CT1 Exact ODE — Potential Function ▾
1
Write in differential form: M(x,y)dx + N(x,y)dy = 0.
2
Check exactness: compute ∂M/∂y and ∂N/∂x. If equal, proceed; if not, the equation is not exact as written.
3
Integrate M w.r.t. x: W(x,y) = ∫M dx + φ(y). The φ(y) is an unknown function of y only.
4
Find φ(y): differentiate W w.r.t. y and set equal to N: ∂W/∂y = N ⟹ dφ/dy = N − ∂/∂y(∫M dx). Integrate to find φ.
5
Write the implicit solution: W(x,y) = C. Solve for y explicitly if possible.
Second-Order Homogeneous ODEs (Constant Coefficients)
CT1 y″ + py′ + qy = 0 — Characteristic Equation ▾
1
Write the characteristic equation: substitute y = e^{mx} to get m² + pm + q = 0.
2
Find roots using the quadratic formula. Compute the discriminant Δ = p² − 4q.
3
Apply the correct case:
  • Δ > 0 (distinct real): y = Ae^{m₁x} + Be^{m₂x}
  • Δ = 0 (repeated): y = (A+Bx)e^{mx}
  • Δ < 0 (complex, m = α±iβ): y = e^{αx}(A cos βx + B sin βx)
4
If an IVP is given, differentiate the general solution, then solve the 2×2 system from y(x₀) = y₀ and y′(x₀) = y₀′.
Generalised example

y″ − 5y′ + 6y = 0: char. eq. m² − 5m + 6 = 0 ⟹ m = 2,3. General solution: y = Ae^{2x} + Be^{3x}.

CT1 y″ + py′ + qy = R(x) — MUC & Variation of Parameters ▾
1
Find the CF: solve the homogeneous equation using the characteristic equation (see above).
2
Identify γ for the free term R(x) = P_n(x)e^{γx}. For trig terms, γ = iω; for polynomials, γ = 0.
3
Check for resonance: is γ a root of the characteristic equation? If yes (multiplicity k), multiply the trial solution by x^k.
4
Write the trial PI from the MUC table (same form as R(x), same degree polynomial). Substitute into the ODE and equate coefficients.
5
GS = CF + PI. Apply ICs if given.
⚠ If R(x) is not a quasi-polynomial (e.g. 1/sin x, ln x), use Variation of Parameters instead: y_p = −y₁∫y₂R/W dx + y₂∫y₁R/W dx where W is the Wronskian of the CF pair.
BVPs, Eigenvalues & Eigenfunctions
CT2 BVP — Finding Eigenvalues & Eigenfunctions ▾
1
Write the ODE in the form y″ + λy = 0 (or similar with a parameter). Identify the two boundary conditions.
2
Split into three cases based on the sign of the separation constant (or roots of the auxiliary equation): λ < 0, λ = 0, λ > 0.
3
For each case, write the general solution (exponentials, constant+linear, or trig) and apply both BCs to get a homogeneous 2×2 system for the constants C₁, C₂.
4
Compute the solvability determinant 𝒟(λ). Set 𝒟(λ) = 0 to find eigenvalues. For λ < 0 and λ = 0, typically 𝒟 ≠ 0 — no eigenvalues.
5
For each eigenvalue, solve the system for C₁, C₂. One will be zero; set the free constant to 1. State the eigenfunction φₙ(x).
Standard result — Dirichlet–Dirichlet

y″ + λy = 0, y(0) = y(L) = 0:

λₙ = n²π²/L², φₙ(x) = sin(nπx/L), n ∈ ℤ⁺.

⚠ The solvability determinant 𝒟 is NOT the same as the Wronskian. 𝒟 can be zero even for LI solutions.
Series Solutions
CT2 Power Series Solution about an Ordinary Point ▾
1
Verify x₀ is ordinary: confirm a(x₀) ≠ 0. The convergence radius satisfies ρ ≥ |x* − x₀| where x* is the nearest singular point.
2
Assume y = Σ_{n=0}^∞ aₙ(x−x₀)ⁿ. Differentiate term by term to get y′ and y″.
3
Substitute into the ODE. Shift summation indices so all series run over the same power (x−x₀)ⁿ. Combine into one sum.
4
Equate coefficients of each power to zero. This gives the recurrence relation (RR) for aₙ.
5
Solve the RR separately for even-indexed and odd-indexed coefficients (each depends on a₀ or a₁ respectively). Write y = a₀y₁ + a₁y₂.
6
Verify W[y₁,y₂](x₀) ≠ 0 to confirm a fundamental system. Check convergence with the ratio test on each series separately.
⚠ Apply the ratio test to the y₁ and y₂ series separately — not to the combined solution y (since a₀ and a₁ are independent).
Systems of First-Order ODEs
CT2 Homogeneous System ẋ = Ax — Eigenvalue Method ▾
1
Find eigenvalues: solve det(A − λI) = 0. Factor the characteristic polynomial.
2
Find eigenvectors: for each λⱼ, row-reduce (A − λⱼI | 0) to REF. Read off the eigenvector vʲ (set free parameter = 1).
3
Write the general solution: x(t) = C₁v¹e^{λ₁t} + ⋯ + Cₙvⁿe^{λₙt}.
4
For an IVP, apply x(0) = x⁰: solve PC = x⁰ where P = [v¹|⋯|vⁿ].

CT2 Inhomogeneous System ẋ = Ax + f(t) — Diagonalisation ▾
1
Find P and P⁻¹: form modal matrix P = [v¹|⋯|vⁿ] and compute its inverse by row reduction.
2

3

Back-transform: x = Py to recover the original solution.
